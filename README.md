## 📚 Sobre este repositório

Este repositório funciona como meu **caderno de estudos de Python**.

Os códigos aqui representam meu processo de aprendizagem, então não têm
necessariamente como objetivo seguir as melhores práticas de programação,
ser os mais eficientes ou ter a implementação mais elegante possível.

Durante os exercícios, posso escrever comentários extensos, repetir
conceitos, utilizar soluções mais simples ou manter estruturas que um
programador mais experiente provavelmente refatoraria.

Isso é intencional: os comentários e a estrutura dos códigos também servem
como **anotações pessoais**, ajudando a registrar o raciocínio utilizado
durante o aprendizado.

> **O objetivo deste repositório é registrar o processo de aprendizagem,
> não apenas o resultado final.**

Com o tempo, pretendo revisitar alguns exercícios e comparar as soluções
antigas com implementações feitas depois de adquirir mais conhecimento.
